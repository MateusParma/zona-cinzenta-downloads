# Zona Cinzenta — instaladores

[Baixar a versão publicada](https://github.com/MateusParma/zona-cinzenta-downloads/releases/latest) · [Jogar pelo navegador](https://zona-cinzenta-game.onrender.com/)

Este repositório contém somente os instaladores públicos e seus verificadores de integridade. O código-fonte e as contas são mantidos separadamente.

## Plataformas

- Windows x64: instalador EXE.
- Mac Apple Silicon: DMG arm64.
- Mac Intel: DMG x64.
- Android 8 ou mais recente: APK assinado para instalação direta.
- iPhone/iPad: use a versão web; o instalador ainda depende de assinatura Apple.

Os mapas estão incluídos. O aplicativo precisa de internet para carregar o código atualizado e conectar os jogadores. As salas particulares rodam no aparelho de quem cria; o anfitrião precisa manter o jogo aberto. Salas públicas continuam no servidor.

Consulte as notas de cada versão para tamanho, verificação SHA-256, limitações e estado das assinaturas. Os pacotes Mac atuais usam assinatura ad hoc sem notarização, e o Windows não possui certificado de editor. Não desative as proteções do sistema. Windows e Android ainda precisam de validação em aparelho físico.
